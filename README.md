🧠 Brain Tumor Detection & AI Report Generation System

 📌 Overview

An AI-powered brain MRI analysis system that detects and classifies brain tumors using deep learning and generates an informative medical report.

The project was sponsored by:

🏥 Vighnahartha Multispeciality Hospital, Ahilyanagar

 🚀 Features

- Brain MRI classification into 4 categories:
  - Glioma
  - Meningioma
  - Pituitary
  - No Tumor

- Image preprocessing using:
  - Bilateral Filtering
  - CLAHE (Contrast Enhancement)

- Deep learning classification using:
  - ResNet-18 Model

- AI-generated report containing:
  - Predicted tumor type
  - Confidence score
  - Tumor description
  - Symptoms
  - General recommendations

- Integrated AI chatbot using:
  - Gemini API
  - Fine-tuned for brain tumor related queries

🛠️ Technologies Used

- Python
- Deep Learning
- Computer Vision
- ResNet-18
- OpenCV
- PyTorch/TensorFlow
- Gemini API

⚙️ Workflow

MRI Image  
↓  
Bilateral Filtering + CLAHE Preprocessing  
↓  
ResNet-18 Classification  
↓  
Tumor Prediction + Confidence Score  
↓  
AI Report Generation  
↓  
Gemini AI Chatbot Assistance

 📊 Output

The system provides:

- Tumor classification result
- Prediction confidence
- Detailed information about detected tumor type
- AI assistance through chatbot

⚠️ Disclaimer

This project is developed for research and educational purposes and should not replace professional medical diagnosis.
